# What's New

Короткая выжимка изменений по датам, новое сверху. Полная документация —
[README.md](README.md), технические детали — `git log`.

## 2026-08-24

- **`/project` — меню с кнопками.** Без аргументов команда теперь показывает
  inline-кнопки по одной на проект (✅ — активный); тап переключает проект,
  меню перерисовывается на месте. `/project <имя>` и `/project add <путь>`
  работают как раньше.
- **Фикс кнопок в старых меню.** Тап по кнопке в удалённом или старше 48 ч
  сообщении теперь присылает свежее меню вместо тихого «ничего не произошло»
  (касается и тогглов `/voice`, `/confirm`, `/draft`, `/reply_voice`, `/note`).
- **Claude больше не путает, где он.** Headless-сессии теперь знают, что
  работают за Telegram-мостом: ответ в чат — только финальный текст. Исчезают
  «план показан выше» и «я не в Telegram» — всё важное приходит в ответе.

## 2026-07-14

- **Голые тогглы показывают статус + кнопку.** `/voice`, `/confirm`, `/draft`,
  `/reply_voice`, `/note` без аргументов отвечают текущим состоянием и
  кнопкой-переключателем прямо в сообщении.

## 2026-06-25

- **Guard на несколько машин.** Если бот уже запущен на другой машине —
  работающий остаётся, новичок молча уступает (без борьбы за getUpdates).

## 2026-06-24

- Фикс: Markdown-ошибки на динамическом тексте (сообщения с `_`/`*` в путях
  молча не отправлялись) — теперь такой текст шлётся как plain.
- Фикс: сообщение single-instance guard печатается один раз, а не спамом.

## 2026-06-23

- **Большой голосовой/текстовый апдейт:** режимы confirm / draft /
  reply_voice, редактирование `/config` кнопками, пагинация длинных ответов.
- Single-instance guard через named mutex — две копии бота на одной машине
  не конкурируют за апдейты.
- Стартовое сообщение ретраится — «пауза» при автозапуске всегда
  сигнализируется владельцу.
- `stop_bot.bat` терпит процессы, исчезнувшие между сканом и kill.
- `setup.bat` — установка в один клик; запуск предпочитает свежий Python
  через `py` launcher.

## 2026-06-22

- Голосовой ввод/вывод (STT Groq / faster-whisper, TTS Edge / Silero) и
  текстовые UX-улучшения — базовый голосовой функционал бота.
