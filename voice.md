Прочитал весь голосовой/текстовый стек. Вот что реально можно сделать в этом проекте — сгруппировано по потокам, с пометками ценности (учитываю: владелец один, телефон, слабый интернет, русский).

Голос → текст (ввод, cmd_voice + transcribe.py)

- Подтвердить распознанное перед отправкой в Claude. Сейчас STT-текст сразу уходит в _do_claude. Показать его с inline-кнопками «✅ Отправить / ✏️ Править / 🗑 Отмена» — экономит токены на кривом распознавании (Whisper ошибается на терминах/именах). Топ для вашего случая.
- Авто-fallback на локальный Whisper. Сейчас stt_provider жёстко из конфига. Groq упал при слабом интернете → запрос дохнет. Сделать: пытаться Groq, при ошибке сети — faster-whisper локально (он уже lazy-подключён). Прямо под ваш «слабый мобильный интернет».
- Склейка нескольких голосовых в один промпт. Сейчас каждое голосовое = отдельный запрос к Claude. Добавить «режим черновика»: голосовые копятся и склеиваются, пока не скажете маркер («отправляй»/«готово») или не нажмёте кнопку. Для длинных голосовых задач по частям.
- Markdown-рендер ответов. Сейчас reply_long шлёт plain-текст (disable_web_page_preview, без parse_mode). Claude часто выдаёт списки/жирный/код — рендерить в MarkdownV2 или HTML с экранированием. Внешний вид сильно улучшится на телефоне.
- Кодовые блоки — отдельно и моноширинно. Выделять ```-блоки в отдельные сообщения моноширинно → удобно копировать с телефона; длинные блоки — как .py/.txt файл.
- Пагинация длинных ответов. Сейчас 5 чанков вываливаются подряд. Сделать кнопки «вперёд/назад» по одному сообщению — не засоряет чат.
- Reply-озвучка — ответить (reply) на любое сообщение бота → озвучить именно его голосом (сейчас только последний через /speak).

Голос ← вывод (speak.py + _speak_answer)

- Выбор голоса на лету — /voice_speaker svetlana|dmitri|dariya (Edge-голоса из конфига). Сейчас голос зашит в tts_edge_voice, сменить можно только правкой файла.
- Скорость речи — /voice_rate +15% (параметр tts_rate уже есть в конфиге, вынести в команду).
- Умная обрезка длинных ответов — сейчас жёстко по 5000 символов с пометкой «озвучены первые символы». Варианты: бить на несколько войсов подряд, или озвучивать только если ответ короткий, иначе присылать текст.
- SSML для естественности — Edge поддерживает паузы/интонацию; лучше звучание списков и цифр.

Голос ↔ гибрид (та самая локальная обработка без Claude)

- Голосовое управление ботом. Обобщение прошлого плана: после STT локальный матчер перехватывает управляющие фразы до Claude — «поставь на паузу», «возобнови», «голосовые вкл», «переключи проект на main», «новый диалог». Архитектура та же (_match_voice_command + диспетчер), просто покрывает все команды, а не только режим. Ровно то, чего вам не хватало: управлять ботом голосом, не тратя токены Claude.
